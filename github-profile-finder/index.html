                        How we calculate this

                        Language Diversity

                        Based on the number of distinct programming languages detected across analyzed public repositories, weighted by how evenly they're used.

                        Repository Diversity

                        Based on the mix of languages, topics and repository types (original, fork, archived) across the developer's public repositories.

                        Activity & Recency

                        Based on repository pushed_at / updated_at timestamps and, where available, recent public events.

                        Community Signal

                        Based on public stars, forks and followers as reported by the GitHub API. It reflects reach, not quality.

                        Consistency

                        Based on how many distinct recent time periods (weeks) show at least one repository update.

                        Developer DNA

                        A visualization derived from observable GitHub metadata. It is not a psychological or professional assessment.
