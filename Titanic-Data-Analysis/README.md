# Titanic Data Analysis

A professional exploratory data analysis project built with **Python, Pandas, NumPy, Matplotlib, and Seaborn** to examine passenger survival patterns in a structured Titanic-style dataset.

The project covers the complete analytics workflow: data ingestion, data-quality assessment, cleaning, feature engineering, statistical analysis, visualization, and presentation of results through an interactive dashboard.

## Live Demo

[View Titanic Data Analysis](https://danya-musbah.github.io/100-Days-100-Projects/Titanic-Data-Analysis/dashboard/)


## Project Overview

This project analyzes a 300-record educational Titanic-style dataset containing passenger demographics, class, fare, family information, and survival outcomes.

The analysis focuses on identifying relationships between passenger characteristics and survival rates while maintaining a reproducible and structured data-analysis workflow.


## Project Overview

The project loads `Titanic_Sample_Data.xlsx` with Pandas, inspects and cleans it, engineers a couple of new features, answers a set of survival-analysis questions with `groupby()`, produces eight charts with Matplotlib/Seaborn, and summarizes the results as a set of key findings — all inside a heavily-commented, educational Jupyter notebook. The same results also power a small interactive HTML/CSS/JS dashboard.

## Dataset

- **Source:** `data/Titanic_Sample_Data.xlsx`, an **educational sample dataset generated for this project**.
- **Important:** This is **not the official historical Titanic dataset**. It resembles its structure (same kinds of columns, same general idea) so it's a realistic, safe playground for learning — but its numbers are not historical fact and should not be presented as such.
- **Structure:** 300 passenger records across 14 columns, plus three supporting sheets in the same workbook: `Data_Dictionary` (explains every column), `Analysis_Questions` (the questions this project answers), and `Notes` (context on the dataset itself).

| Column | Meaning | Type |
|---|---|---|
| `PassengerId` | Unique passenger identifier | Integer |
| `Survived` | 1 = survived, 0 = did not survive | Binary |
| `Pclass` | Passenger class: 1, 2, or 3 | Integer |
| `Name` | Passenger name | Text |
| `Sex` | Passenger sex | Category |
| `Age` | Passenger age | Numeric |
| `SibSp` | Number of siblings/spouses aboard | Integer |
| `Parch` | Number of parents/children aboard | Integer |
| `Ticket` | Ticket identifier | Text |
| `Fare` | Ticket fare | Numeric |
| `Cabin` | Cabin identifier; intentionally contains missing values | Text |
| `Embarked` | Port of embarkation: C, Q, S | Category |
| `FamilySize` | `SibSp + Parch + 1` | Derived |
| `IsAlone` | 1 if travelling alone, otherwise 0 | Derived |

Missing values are intentionally included in the dataset so the project can demonstrate real data-cleaning decisions.
